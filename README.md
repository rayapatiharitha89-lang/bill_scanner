# 🧾 Bill Scanner App

A web application that scans receipt images and extracts structured data using OCR.

## 🚀 Features
- 📷 Upload receipt images
- 🔍 OCR text extraction
- 📊 Parsed bill details
- 💾 SQLite database
- 📈 Spending dashboard with charts
- 📱 Mobile friendly

## 🛠️ Tech Stack
- Python, Flask
- Tesseract OCR
- SQLite, SQLAlchemy
- HTML, CSS, JavaScript, Chart.js

## ⚙️ Installation
1. Install dependencies:
pip install flask flask-sqlalchemy pytesseract pillow

2. Install Tesseract OCR:
https://github.com/UB-Mannheim/tesseract/wiki

3. Run:
python app.py

4. Open browser:
http://127.0.0.1:5000
